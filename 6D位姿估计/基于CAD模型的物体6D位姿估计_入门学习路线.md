# 基于 CAD 模型的物体 6D 位姿估计：学习路线

> 本路线结合已有的坐标变换与点云基础，并使用已下载解压的 YCB-V BOP 子集，从 BOP 标注与 CAD 模型的对应关系开始，逐步进入位姿估计算法。

## 1. 最终需要解决的问题

给定一张相机图像和一个物体的 CAD/3D 模型，估计物体相对于相机的位置和朝向。结果通常表示为物体坐标系到相机坐标系的刚体变换：

$$
\mathbf{p}_C = \mathbf{R}_{CO}\mathbf{p}_O + \mathbf{t}_{CO},
\qquad
\mathbf{T}_{CO}=\begin{bmatrix}\mathbf{R}_{CO}&\mathbf{t}_{CO}\\0&1\end{bmatrix}.
$$

其中有 3 个旋转自由度和 3 个平移自由度。下标 CO 表示这个变换把物体坐标系 O 中的点变到相机坐标系 C 中。

### 先把四个容易混淆的概念分开

1. **测试时有 CAD（model-based）**：方法可使用目标的三维模型作为先验。这只描述测试时可用的信息，不说明训练方式。
2. **训练时见过该物体（seen）**：这是学习方法和 BOP 基准中的设定，指训练样本包含该具体物体实例及相应监督。它不等于“必须为这个物体单独训练一套网络”；网络可以在多个物体上共享训练。
3. **训练时未见该物体（unseen）**：训练样本不含测试中的具体物体。测试时仍可提供 CAD 或其他 onboarding 信息。通用网络训练和新物体适配/准备是两件事。
4. **为 CAD 生成模板**：从新 CAD 渲染多视角图像或计算特征，是对象级预处理，不等同于神经网络训练。论文有时把离线模板构建称为 training/setup 阶段，阅读时需看清具体是在优化网络参数，还是只在建立模板库。

因此，PPF 和 ICP 这类几何方法可在推理时直接使用 CAD 与观测几何，不需要神经网络训练；PPF 可为具体模型建立几何特征索引，ICP 则对当前初始位姿做局部迭代细化。LINEMOD 需要从 CAD 建立视角模板库，但模板生成本身不是神经网络训练。

BOP 的 seen/unseen 任务术语主要区分学习方法是否在训练数据中接触过测试物体；model-based 描述的是方法可使用模型先验。[BOP 任务定义](https://bop.felk.cvut.cz/tasks/)。

### 一个实际估计系统大致由什么组成？

~~~text
输入图像 + 相机参数 + CAD 模型
                ↓
   找到目标（类别/实例、检测框或掩码）
                ↓
  粗略位姿候选（模板、对应关系或几何匹配）
                ↓
          位姿细化
                ↓
   输出 T_CO，并用图像/指标检查结果
~~~

阶段一暂时不运行这条“估计”链，而是拿数据集的真值位姿把链路反向跑通：确认图像、CAD、相机参数和标注彼此一致。

## 先建立算法地图

正式处理数据前，先明确一条 6DoF 位姿估计流程的输入和输出：输入可以是 RGB、RGB-D 或场景点云，可用信息可以包括 CAD、相机内参和目标区域；输出是物体坐标系到相机坐标系的刚体变换 \(T_{CO}\)，或若干待筛选的位姿候选。还要说明目标区域是由方法检测得到还是由外部提供、初始位姿如何产生，以及是否进行后续细化。

常见方法可按位姿候选的来源理解：

- **几何模型匹配**：从 CAD 与场景点云的几何关系生成位姿候选，例如 PPF。
- **图像模板匹配**：从 CAD 渲染多个视角模板，再从图像匹配视角，例如 LINEMOD。
- **对应关系与几何求解**：建立图像像素与模型三维点的 2D-3D 对应，再用 PnP/RANSAC 求位姿；EPOS 是一个例子。
- **学习式估计**：网络预测位姿、对应关系或候选评分，后续可结合优化细化；DenseFusion、MegaPose 和 FoundationPose 可作为不同方向的阅读入口。

阶段零先以 PPF 为例读一条完整的几何位姿估计方法：标出它需要的 CAD 与场景点云、如何产生位姿候选、输出变换表示什么。再把它与模板匹配、2D-3D 对应加 PnP 作对照。之后再进入数据核验和点云练习，准备并检查这些方法所需的输入。

这张地图用于识别方法各自解决哪一段问题。数据核验和点云练习帮助理解输入、坐标系与误差来源，不应与完整位姿估计算法混为一谈。

### 阶段一：读懂 BOP 样本，把真值位姿下的 CAD 投回图像

**一句话：** 数据集已经给出真值位姿。本阶段将对应 CAD 按真值变换到相机坐标，再投影到原图，检查几何链路是否接通。

这不是位姿估计算法。它是在给后续算法排除数据问题：如果真值位姿都不能把 CAD 投到物体附近，之后网络预测不贴合时，就无法判断是算法错了还是坐标、单位、相机参数或模型编号错了。

#### 本阶段实际做的步骤

1. 找到 YCB-V 测试子集中的一个场景和图像。
2. 读取该图像的物体实例列表。实例是图像中一个具体物体的一次单独出现，每条标注记录对应一个实例；gt_id 是它在当前图像列表中的序号，obj_id 对应 models/obj_XXXXXX.ply。若同一模型出现两次，两条记录的 obj_id 相同，但 gt_id 和真值位姿各自独立。
3. 从同一帧的 scene_gt.json 读真值 cam_R_m2c、cam_t_m2c；从 scene_camera.json 读当前帧相机内参 cam_K。
4. 从 CAD 三角网格表面均匀采样点，显示物体坐标系 O 中的 CAD 点云。
5. 用真值 T_CO 把同一批 CAD 点变到相机坐标系 C，再显示变换后的点云；这两幅图帮助观察位姿如何改变点的位置和朝向。
6. 用真值 T_CO 将 CAD 包围盒角点从物体坐标变到相机坐标，再用 K 投影为像素。
7. 把黄色包围盒和 RGB 三色坐标轴画回图像。
8. 反算投影点，检查投影、反投影和逆变换的计算是否互相一致。

**会看到什么：**一组并排的 3D 图：左边是物体坐标系 O 中的 CAD 点云，右边是同一批点经真值位姿变换后在相机坐标系 C 中的位置；随后还会看到 RGB 图像上的黄色 CAD 包围盒和红绿蓝坐标轴。3D 图中的点来自 CAD 表面采样，不是深度图测得的场景点云，也不是算法估计结果。包围盒应大致罩住目标；遮挡时，完整模型的投影大于可见部分是正常的。

**完成标准：**能够说出场景号、图像号、实例 gt_id、模型 obj_id 和 CAD 文件名；解释 T_CO 的方向；并说明图像叠加核对的是数据与几何链路，不是算法估计精度。

对应代码文件：[阶段一 BOP 样本的 CAD 位姿投影核验](./01-BOP样本的CAD位姿投影核验.ipynb)。

### 阶段二：用深度图和 CAD 建立点云对应

本阶段将已有的点云知识应用到 YCB-V 上。阶段一使用 RGB 和真值位姿；阶段二加入深度图，检查真实观测表面与完整 CAD 模型之间的关系。

**动手步骤**

1. 读取当前帧 depth、scene_camera.json 和对应的 mask_visib。
2. 按该数据集的 depth_scale 将深度转换为毫米，再用相机内参反投影到相机坐标系。
3. 使用可见掩码只保留所选实例的可见深度点。
4. 从 CAD 网格采样点，并用真值 T_CO 变换到同一个相机坐标系。
5. 同屏显示观测点云和变换后的 CAD 点云，观察遮挡、深度空洞、边缘噪声、模型不可见背面。

**完成标准：**能解释为什么 RGB-D 只得到物体可见部分，而 CAD 是完整表面；能检查两组点是否处于同一坐标系和单位。

对应代码文件：[阶段二：深度图与 CAD 点云对照](./02-深度图与CAD点云对照.ipynb)。

### 阶段三：几何位姿估计——PPF 粗位姿与 ICP 局部细化

先学习如何从 CAD 模型和场景点云产生物体位姿候选，再学习如何优化一个已有初值。PPF 是几何路线中的位姿候选生成方法：它利用模型与场景的点对特征匹配和投票，得到物体在场景中的位姿。ICP 则是刚体点云配准算法：在给定两组点云和初始变换后，反复建立近邻对应并减小几何残差。

从数学结果看，ICP 求解的也是完整 6DoF 刚体变换 \((R,t)\)。在物体位姿估计系统中，它通常承担局部配准或细化：它本身一般不负责检测目标，也不负责从杂乱场景中提出可靠的全局初始候选。因此学习时先理解完整位姿候选如何产生，再用 ICP 观察候选如何细化。

**学习步骤**

1. 按“模型点对特征建库—场景点对匹配—参考点与角度投票—位姿候选聚类”梳理 PPF 流程，并标出法线、量化步长和目标区域对输入的要求。
2. 运行 Notebook 中的 PPF 粗位姿估计：从 BOP 可见掩码提取观测点云，记录投票支持度和粗位姿 \(T_{CO}\)，并与真值比较。此处真值只用于误差分析，不输入 PPF。
3. 将 PPF 候选交给 ICP 做细化，比较细化前后的位姿误差、匹配比例和 RMSE，观察 ICP 是否改善当前候选。
4. 再比较真值扰动初值下的 ICP 结果。该对照用于观察初值影响，不能当作 PPF 估计结果。

**阅读起点：**Drost 等人的 [Point Pair Features (PPF)](https://campar.in.tum.de/pub/drost2010CVPR/drost2010CVPR.pdf)；实现流程见 [PPF 算法笔记](./PPF算法.md)，之后阅读 [ICP 算法笔记](./ICP算法.md)。

**完成标准：**能说明 PPF 如何提出几何位姿候选、ICP 如何细化候选；能根据实验判断 ICP 是否改善了 PPF 初值；能指出本练习使用 BOP 真值可见掩码，因此没有评估目标检测或分割。

对应 Notebook：[阶段三：PPF 粗位姿估计与 ICP 位姿细化演示](./03-PPF%20粗位姿估计与%20ICP%20位姿细化.ipynb)。该练习串联了 PPF 候选生成和 ICP 局部细化；目标区域由真值掩码提供，不作为包含目标检测/分割的端到端系统评测。

理论说明：[ICP 算法笔记](./ICP算法.md)。

### 阶段四：图像位姿方法——模板、对应关系与 PnP

已知 CAD 不代表图像里已经知道目标位置。很多系统还要检测或分割目标，再从图像线索产生位姿候选。

**两条容易上手的路线**

- **渲染模板：**从 CAD 渲染许多视角，和目标图像或目标区域匹配，先找粗略朝向。LINEMOD 是经典起点。
- **2D-3D 对应 + PnP：**找图像像素与 CAD 三维点的对应，再用相机内参和 PnP 求位姿；用 RANSAC 抵抗错误对应。

**动手步骤**

1. 用阶段一的真值位姿生成几张 CAD 渲染模板，改变朝向观察模板变化。
2. 人工指定若干个 CAD 三维点，并用已知真值位姿投影成 2D 点。
3. 从这些 2D-3D 对应运行 PnP；加入少量错误匹配，再比较普通 PnP 与 RANSAC。
4. 把求出的位姿再次投影回图像；学习“估计 → 重投影 → 查误差”的闭环。

**阅读起点：**[LINEMOD](https://www.stefan-hinterstoisser.com/papers/hinterstoisser2012accv.pdf)、[EPOS](https://openaccess.thecvf.com/content_CVPR_2020/html/Hodan_EPOS_Estimating_6D_Pose_of_Objects_With_Symmetries_CVPR_2020_paper.html)。

**完成标准：**能区分检测/分割、模板或对应关系、PnP、位姿细化分别负责什么；知道阶段一画出的真值投影图只是校验工具。

### 阶段五：BOP 数据集和评测

BOP 提供统一的数据格式和评测入口。官方的 BOP-Classic-Core 包含 LM-O、T-LESS、ITODD、HB、YCB-V、IC-BIN 和 TUD-L 等数据集；不同数据集能检验不同场景难点。[BOP 官方数据集说明](https://bop.felk.cvut.cz/datasets/)

| 数据集 | 适合学习的难点 | 建议顺序 |
|---|---|---|
| YCB-V | 日常物体、RGB-D、杂乱场景和遮挡 | 当前阶段正在用 |
| LM-O | 遮挡较强的场景 | 学会基本流程后增加 |
| T-LESS | 纹理少、几何相似、对称性明显的工业物体 | 学习几何歧义和对称评测 |
| 其余 BOP-Classic-Core | 工业传感器、不同物体材质与场景 | 需要扩展测试时再加入 |

**需要掌握**

- BOP 格式中的图像、相机参数、GT 位姿、模型和目标列表如何对应。
- 定位与检测、已见与未见、RGB 与 RGB-D 是不同实验设定，不能混在一起比较。
- VSD、MSSD、MSPD 处理的误差侧重点不同；AR 是 BOP 常用汇总指标。
- 对称物体可能有多个视觉上等价的姿态，评测需要考虑对称性。

**数据使用原则：**当前下载的 BOP'19-24 子集只用于读取和几何可视化，不拿测试数据训练。真正训练或比较算法时，要按官方划分准备训练/验证数据，并使用 BOP 工具和官方任务设定。YCB-V 原始数据附带的 80K 合成训练图像有已知的训练/测试姿态重叠问题；下载训练数据前先遵循 [BOP YCB-V 页面说明](https://bop.felk.cvut.cz/datasets/)。

**完成标准：**读懂一个数据集的 train/test 结构，能说明当前实验使用的输入、物体先验、标注和指标，并能避免用测试数据训练。

**完成标准：**能说明“训练时不见某物体”仍然可以在测试时使用该物体 CAD；能区分无需逐物体训练、无需检测框、无需模型预处理这些不同主张。

### 阶段七：小型结课项目

选 YCB-V 的一个物体，做出一个可解释、可复现的小系统。先固定已知目标区域，避免一开始把检测错误和位姿错误混为一谈：

1. 读取 RGB、相机参数、CAD 和标注；先复用阶段一的数据检查。
2. 使用标注框或掩码，隔离位姿模块，避免检测误差干扰初始学习。
3. 实现一条粗位姿路线：几何匹配、渲染模板或 2D-3D 对应三选一。
4. 试着用 ICP 或 render-and-compare 做细化。
5. 将估计位姿下的 CAD 投影/渲染回图像，和阶段一的真值投影并排查看。
6. 按遮挡、深度噪声、对称物体、模型尺寸和错误匹配整理失败案例。
7. 用合适的 BOP 任务设定和指标记录结果；报告输入条件和数据划分。

**最终留下：**一份运行说明、一张真值与估计结果对照图、一张指标表、若干失败案例，以及对当前方法适用条件的说明。

## 4. 六周学习安排（可按进度放慢）

| 周次 | 学习内容 | 当周完成物 |
|---|---|---|
| 第 1 周 | 阶段零：算法地图与 PPF 阅读；阶段一：BOP 样本、obj_id/CAD 对应、真值投影 | 画出 PPF 流程，并解释叠加图每种线和每个编号 |
| 第 2 周 | 阶段二：深度反投影、可见点云与 CAD 点云 | 生成并查看同坐标系点云 |
| 第 3 周 | 阶段三：运行 PPF 粗位姿到 ICP 细化，并比较真值扰动初值 | 说明粗位姿与局部细化的区别，比较细化前后的结果 |
| 第 4 周 | 阶段四：模板、对应关系、PnP/RANSAC | 用真值投影点恢复一个位姿 |
| 第 5 周 | 阶段五：BOP 数据划分和指标 | 读懂一个官方评测结果 |
| 第 6 周 | 阶段六选读一篇 + 阶段七小项目 | 写出方法流程和实验边界 |

每周学习时间较少时，可完成阶段零到五，再阅读现代方法论文。训练模型前，应先能清楚解释模型坐标系与相机坐标系的关系，并说明所选方法如何产生位姿候选。
